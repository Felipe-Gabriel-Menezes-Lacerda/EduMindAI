# Scripts

Esta pasta contém scripts e prompts para acelerar a criação do projeto no Trae.

- `prompt-trae-master.md`: prompt completo para pedir ao Trae para montar, revisar e finalizar o projeto.
- `create-solution.sh`: comando base para criar a solução .NET e orientar o front-end.
- `create-solution.ps1`: versão PowerShell.
