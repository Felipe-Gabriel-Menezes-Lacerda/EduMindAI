# Roteiro de Execução para Hackathon

## MVP mínimo

1. Login visual ou mockado.
2. Dashboard do aluno.
3. Diagnóstico com 5 a 8 questões.
4. Resultado do diagnóstico.
5. Trilha personalizada.
6. Dashboard do professor.
7. EduMint Quest com criação de gincana e prévia gerada por IA.
8. Missão gamificada para aluno.

## O que cortar no início

- Cadastro completo de escola.
- Relatórios PDF complexos.
- Gamificação avançada com mapa 3D.
- Loja de avatares.
- Módulo de pais.
- Animações pesadas.

## Demonstração ideal

1. Mostrar aluno realizando diagnóstico.
2. Mostrar resultado: dificuldade em divisão.
3. Mostrar trilha personalizada gerada.
4. Entrar como professor.
5. Mostrar mapa de defasagem da turma.
6. Criar gincana no EduMint Quest.
7. Mostrar missão gamificada do aluno.

## Frase de pitch

O EduMint AI identifica onde o aluno travou, cria uma trilha para recuperar a aprendizagem e transforma o estudo em missões gamificadas que aumentam o engajamento.
